about=Tembuku helps FTTH/GPON designers with the first stage of feeder design. Choose a folder of KMZ files (cable inventory, feeder design compilation, distribution or design-lite FDT points, POP list): Tembuku recognises each file from its content, corrects and lists small typing mistakes in folder names, FDT codes and coordinates, and stops with a clear message when a required file is missing or unsafe. For each FDT it checks the free tubes of nearby feeders, whether the feeder really runs toward the FDT, the tap point, the new cable route along existing poles and roads (OpenStreetMap, cached) and the GPON optical budget using the maximum values of current ITU-T standards, then decides between reusing a feeder and building a new one. Results: KMZ files in the compilation folder layout with automatic F/T numbering, styled QGIS layers, an interactive offline HTML report, a CSV summary, and an accuracy test against existing designs. Click an FDT on the map for an instant answer, or choose another candidate in the results panel. An offline help page with a glossary is included. Decision rules were calibrated on real approved designs and every value can be changed. No company names are built in; optional company labels stay in a local file. Large KMZ files are indexed once for the work area; files are read safely (no extraction, size limits, no DTD). No extra Python packages. The interface is in English; reports are written in Indonesian.
